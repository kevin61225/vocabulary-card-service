# Vocabulary Card Service - API Specifications

This directory contains the API specifications for the Vocabulary Card Service, following a spec-driven design approach.

## Overview

The Vocabulary Card Service is a language learning API that allows users to create and manage vocabulary cards for learning different languages.

## Specifications

### Phase 1 - Core Features

1. [Vocabulary Card Creation](./vocabulary-card-creation.md) - Creating new vocabulary cards
2. [Vocabulary Card Management](./vocabulary-card-management.md) - Managing and organizing vocabulary cards
3. [User Management](./user-management.md) - User registration, authentication, and profile management

## API Design Principles

- RESTful API design
- Spec-driven development using OpenAPI/Swagger
- JWT-based authentication
- Versioned API endpoints (v1)

## Getting Started

Please refer to each specification file for detailed API endpoints, request/response formats, and business rules.
